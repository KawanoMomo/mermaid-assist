# ADR カテゴリ

| カテゴリ | 説明 | 例 |
|---|---|---|
| **アーキテクチャ** | システム全体の構造、レイヤ分割、モジュール境界 | ADR-011 (JS外部分割) |
| **インターフェース** | モジュール間API、契約、抽象化 | ADR-012 (DiagramModule v2), ADR-014 (groups model), ADR-017/026 (auto-quote), ADR-022 (ID 命名), ADR-027 (更新関数のシグネチャ), ADR-028 (並べ替えの意味), ADR-029 (kind の別名) |
| **インタラクション** | ユーザー操作モデル、UIメタファ、入力デバイス | ADR-013 (Connection Mode) |
| **UI/UX** | レイアウト、視覚デザイン、操作の一貫性 | ADR-015 (縦一列フォーム), ADR-021 (overlay CSS 汎用化), ADR-031 (欄名の3語) |
| **テスト戦略** | テスト設計手法、ツール選定、カバレッジ目標 | (今後) |
| **エージェント運用** | サブエージェント設計・連携・責務分割 | ADR-016 (system-tester 連携), ADR-019 (cache clear) |
| **性能** | 応答時間、描き直しの頻度、大きな図での挙動 | ADR-030 (描き直しの待ち時間) |
| **プロセス** | 進め方、記録の残し方、先送りの管理 | ADR-032 (先送りの前提を機械が見張る) |
| **配布・運用** | ビルド、リリース、互換性、ライセンス | (今後) |
